# 🎬 Movies App

A simple movies browsing app built with **Vite + React** that fetches data from [The Movie Database (TMDB)](https://www.themoviedb.org/).  
The app allows users to explore popular movies, view details, and search for titles using TMDB’s public API.  

Live Demo: [https://movies-dn4m5chuz-ndumisomenzs-projects.vercel.app/](https://movies-dn4m5chuz-ndumisomenzs-projects.vercel.app/)

---

## 🚀 Project Overview
- Built with **React + Vite**  
- Styled with **[add your CSS framework if used: TailwindCSS, CSS Modules, etc.]**  
- Data fetched from **TMDB API**  
- Deployed on **Vercel**  

### Features
- Browse popular movies  
- Search for movies by title  
- View movie posters, ratings, and details
